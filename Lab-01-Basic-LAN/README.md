# Lab 01 - Basic LAN

## Objective
Connect two PCs using one switch and verify connectivity.

## Topology
- 1 Cisco Switch
- 2 PCs

## IP Configuration

| Device | IP Address |
|---------|------------|
| PC0 | 192.168.1.10 |
| PC1 | 192.168.1.11 |

## Steps
1. Connect both PCs to the switch.
2. Configure IP addresses.
3. Test connectivity using ping.

## Result
Both PCs successfully communicated with each other.
